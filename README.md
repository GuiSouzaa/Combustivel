# ⛽ Comparador de Combustível

Aplicativo Android simples criado com o objetivo de **verificar se é mais vantajoso abastecer com álcool ou gasolina**, com base no valor informado pelo usuário.

---

## 📲 Funcionalidades

- Entrada do valor do **álcool** e da **gasolina**;
- Cálculo baseado na fórmula padrão:  
  > Se (álcool / gasolina) < 0.7 → **Álcool é mais vantajoso**, caso contrário, **Gasolina**;
- Exibição do melhor combustível;
- Interface simples e direta para uso rápido.
